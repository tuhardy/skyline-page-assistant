## 已确认的产品方向

## 可扩展、可增减的功能模块

每个功能模块包含：

- 模块 ID、显示名称、版本和启用状态。
- 真实菜单定位规则及页面识别规则。
- 当前值读取适配器。
- 分步指导定义和真实控件定位器。
- 变更预览、执行和回读验证器。
- 风险说明及是否需要保存/重启。

模块管理分两档：

1. **导航/只读模块**：可通过声明式配置添加菜单名称、真实页面匹配和提示文字，也可禁用或删除。
2. **代操作模块**：必须有经过实机验证的适配器，不能仅靠用户填写一个 URL 就获得写操作能力。

MV3 不远程下载或动态执行代码。带写操作的模块随扩展版本 bundled 安装；用户可启用、禁用或从自己的工作台移除，不修改设备上的菜单。

优先接入顺序：

1. IMEI。
2. EIMS/ETMS：先查清各自真实配置区和注册状态，不能混为一个功能（两者均已完成真实表单直填注册指导，保持相互独立）。
3. SMS Control。
4. 通话时长、呼叫次数、通话号码、呼叫控制等语音模块。
5. Save and Reboot：读取真实页面后单独实现，重启必须二次确认。

## 安全和验收约束

- 不保存登录密码，不上传设备配置或浏览数据。
- 修改前读取原值并显示目标范围；批量操作必须显示变更数量。
- 真实页面状态在预览后发生变化则停止执行。
- 只点击已确认的真实按钮，不绕过设备校验。
- 成功必须由回读证明；延迟、超时和缺失控件均如实显示为未确认或不一致。
- 保存和重启是独立高风险动作，不因 IMEI 保存成功而自动执行。
- 每新增一个模块，先在测试设备完成读取、指导、修改、延迟回读和恢复路径验证，再扩展下一模块。
